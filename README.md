
# RZ Inventarios

### Sistema web de gestión y control de inventarios

**RZ Inventarios** es un proyecto de desarrollo de software orientado a facilitar el registro, administración y consulta de productos de inventario para la empresa Multiservicios Fachadas S.A.S.

## Objetivo del proyecto

Desarrollar una aplicación web que permita organizar la información de los productos y facilitar el seguimiento de las cantidades y valores del inventario.

## Funcionalidades

- **Panel principal:** visualización de indicadores generales del inventario.
- **Registro de productos:** permite agregar productos con su información.
- **Edición de productos:** permite actualizar los datos registrados.
- **Eliminación de productos:** permite retirar registros.
- **Inventario:** consulta de los productos registrados.
- **Reportes:** consulta de cantidades, categorías y valores del inventario.

## Tecnologías utilizadas

- PHP
- MySQL
- HTML
- CSS
- Visual Studio Code
- XAMPP

## Entorno de desarrollo

El proyecto se ejecuta actualmente en un entorno local mediante XAMPP.

Para acceder desde el navegador:

`http://localhost/rz-inventarios/index.php`

## Estructura del proyecto

- `index.php`: página principal.
- `agregar.php`: registro de productos.
- `editar.php`: edición de productos.
- `eliminar.php`: eliminación de productos.
- `reportes.php`: módulo de reportes.
- `estilos.css`: estilos y diseño visual.
- `conexion.php`: conexión local con la base de datos (no se publica en GitHub).
